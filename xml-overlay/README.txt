Arctic Fuse 2 Touch — XML 覆盖包

这个小包不是完整皮肤，不能在 Kodi 里「从 zip 安装」。
完整安装请用聊天里那份 64MB 的 skin.arctic.fuse.2-2.12.12.touch.zip。

如果你已经装了 Arctic Fuse 2：
1. 解压这个包
2. 把 COPY-INTO-skin.arctic.fuse.2 里面的文件，覆盖到已安装的皮肤目录
   Android 常见路径：
   Android/data/org.xbmc.kodi/files/.kodi/addons/skin.arctic.fuse.2/
3. 重启 Kodi，或皮肤设置里 Reload

不要删 media/ 和 extras/，贴图必须留着。
