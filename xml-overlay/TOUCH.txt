# Arctic Fuse 2 Touch

Based on Arctic Fuse 2 2.12.12 (jurialmunkey), CC BY-NC-SA 4.0.

This fork keeps the original look. It ports Estouchy-style *control logic* for phones and tablets:

- On-screen back / home / side menu / search / view / context using AF2 circle icons in the empty bottom-center furniture slot
- Home side menu can be opened by tapping the menu icon (AF2 normally hides it until a remote focuses it)
- Hub categories are tappable (AF2 zeroed their hitrects for D-pad)
- Fullscreen OSD shows a seek nib you can drag, plus home and close
- Skin Settings → hide the touch bar if you only use a remote

Install: Kodi → Add-ons → Install from zip file → this archive. Same addon id as Arctic Fuse 2, so it updates in place.
